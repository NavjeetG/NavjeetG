## 🌐 Deploy to GitHub Pages in 2 Minutes

1. **Initialize Git & Push**:
   ```bash
   git init
   git add .
   git commit -m "Deploy Navjeet Singh portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-github-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. **Enable GitHub Pages**:
   - Go to your repository on GitHub $\rightarrow$ **Settings** $\rightarrow$ **Pages**.
   - Under **Build and deployment** $\rightarrow$ **Branch**, select `main` and folder `/ (root)`.
   - Click **Save**.
3. Your portfolio is live at `https://<your-github-username>.github.io/<your-repo-name>/`!
